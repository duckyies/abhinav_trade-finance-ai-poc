# Trade Finance Assistant

A simple React-based FAQ chatbot and knowledge base management system for trade finance topics.

## Features

* Chat interface for asking questions about trade finance topics
* FAQ knowledge base management
* Add, edit, delete, and search FAQs
* Suggested related topics based on user queries

## Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm start
```

3. Open your browser and visit:

```text
http://localhost:3000
```

## Project Structure

* `Chatbot` – Ask questions from the FAQ knowledge base
* `FAQ Manager` – Manage FAQ entries
* `Analytics` – Placeholder page
* `History` – Placeholder page

## Notes

* FAQ data is loaded from `faqs.json`.
* Changes made in the FAQ Manager are currently stored only in memory and will reset when the application reloads.

## Technologies Used

* React
* JavaScript
* HTML/CSS (inline styling)
